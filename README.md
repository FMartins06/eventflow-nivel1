# EventFlow

Aplicativo desktop para gerenciamento de eventos, desenvolvido em Python
para a disciplina de Programação Orientada a Objetos.

## Funcionalidades

- Cadastro e login de organizadores e participantes
- Cadastro, edição e cancelamento de eventos pelo organizador responsável
- Registro de interesse de participantes
- Controle de vagas e lista de espera
- Contratação, cancelamento e substituição de equipes de divulgação

## Bibliotecas utilizadas

- `tkinter`: criação da interface gráfica.
- `tkinter.ttk`: botões, campos, listas e outros controles visuais.
- `tkinter.messagebox`: mensagens e confirmações ao usuário.

Todas fazem parte da biblioteca padrão do Python. O projeto não usa pacotes externos instalados com `pip`.
